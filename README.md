# Harihar Cargo Bill Generator

A responsive web application to generate professional cargo bills with A4 layout support.

## Features

- Live bill preview
- PDF download
- Print support
- WhatsApp PDF sharing
- Excel data storage
- Mobile responsive UI
- A4 paper size layout

## Technologies Used

- HTML
- CSS
- JavaScript
- GitHub Pages
