# Vision

Build a professional, scalable and reusable Transport Management System for car carrier businesses.

The software should first work for Harihar Car Carriers and later be customizable for other transport companies with minimal changes.

---

# Goals

- Keep all existing features.
- Improve UI & UX.
- Add authentication.
- Add user roles.
- Add permissions.
- Add customer management.
- Add driver management.
- Add trailer management.
- Add vehicle management.
- Add document management.
- Add QR support.
- Add reports.
- Add analytics.
- Add notifications.
- Make the software reusable.
- Make the code clean and maintainable.
- Build it as a commercial product, not just a college project.

---

# Development Rules

- No feature will be developed without planning.
- Every module will be designed before coding.
- Every change will be committed to Git.
- Code should be modular and reusable.
- UI should be responsive.
- Security will be considered from the beginning.
